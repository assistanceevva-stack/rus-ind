# Часть 0 — Ответы на вопросы (Фаза 2-lite)

## 1) Базовый URL фронта в dev/preview

| Режим | Порт | Base path | URL |
|-------|------|-----------|-----|
| **dev** (`npm run dev`) | 8080 | `/` | `http://localhost:8080/` |
| **preview** (`npm run preview`) | 4173 (дефолт Vite) | `/` | `http://localhost:4173/` |

Источник: `frontend/vite.config.ts` — `server.port: 8080`. Для preview Vite по умолчанию использует 4173 (если не задан `--port`).

## 2) Форма обратной связи

**Есть две формы:**

| Компонент | Где находится | Обязательные поля | Куда отправляет |
|-----------|---------------|-------------------|-----------------|
| **ContactForm** | Главная (`/`), секция `#contact` | `name`, `company`, `email` | **Никуда** — только toast |
| **ContactDialog** | Header (кнопка «Запрос КП») | `name`, `company`, `email` | localStorage + скачивание JSON + toast |

**Важно:** обе формы **не обращаются к бэкенду**. ContactForm — чистый mock (toast). ContactDialog — сохраняет в localStorage и скачивает JSON. Для E2E это **стабильно**: не зависит от бэка, не нужны секреты.

## 3) Как фронт общается с бэком

| Что | Как | Где настроено |
|-----|-----|---------------|
| **ChatWidget** | Прямой URL `http://localhost:3001` | Захардкожено в `frontend/src/ChatWidget.tsx:30` |
| **Формы** | Не общаются с бэком | — |
| **Vite proxy** | Нет | — |
| **Env переменная** | Нет | — |

```ts
// ChatWidget.tsx:30
const API_BASE = "http://localhost:3001";
```

## 4) Успешное сообщение формы

- **Toast** (Radix UI): `title: "Заявка отправлена"`, `description: "Мы свяжемся с вами в ближайшее время"`
- **Компонент:** `Toaster` из `@/components/ui/toaster` (используется `useToast` из `@/hooks/use-toast`)
- **Проверка успеха:** искать текст `"Заявка отправлена"` или `"Мы свяжемся с вами в ближайшее время"` в DOM (role/aria или data-testid)

## 5) Нужны ли для E2E реальные .env секреты?

**Нет.** Для выбранных сценариев:

- **Форма обратной связи** — не использует бэк, секреты не нужны.
- **Чат** — при недоступном бэке ChatWidget переходит в **offline-режим** и отвечает локальной `offlineAI()`. Секреты не нужны.

**Бэкенд** (если понадобится для чата):
- Запускается без Google Sheets — просто логирует в консоль.
- `.env.example`: `SHEET_ID`, `GS_CLIENT_EMAIL`, `GS_PRIVATE_KEY` — опциональны.
- Для CI: можно запускать бэк с пустым `.env` — он будет работать, просто без записи в таблицу.

**Рекомендация:** E2E без бэка (форма + главная) или с бэком на тестовом env (пустой `.env`) — секреты не требуются.

## 6) Альтернативный сценарий №2, если форма нестабильна

Форма **стабильна** (mock, без бэка). Но если понадобится запасной вариант:

| Сценарий | Сложность | Нужен бэк? | Рекомендация |
|----------|------------|------------|--------------|
| **Навигация по страницам** | Низкая | Нет | ✅ Простой, надёжный |
| **Открытие чата** | Низкая | Нет | ✅ Кнопка «💬 Чат» → окно чата |
| **Отправка сообщения** | Средняя | Нет* | ✅ При недоступном бэке — offlineAI, ответ всё равно появится |

\* ChatWidget при ошибке fetch показывает: «⚠️ Сейчас я работаю в автономном режиме» + локальный ответ. E2E может проверить появление ответа.

**Вывод:** для E2E оптимальны:
1. Главная открывается
2. Форма обратной связи (ContactForm на `/`) — заполнить, отправить, проверить toast

Альтернатива: навигация `/` → `/equipment` → `/honest-mark` или открытие чата + отправка сообщения (работает и без бэка).
