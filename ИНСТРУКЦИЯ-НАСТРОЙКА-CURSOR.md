# Инструкция для чайника: как настроить Cursor, чтобы AI мог запускать сайт сам

Пошаговая инструкция с нуля. Делайте всё по порядку.

---

## Часть 1. Открыть настройки Cursor

### Способ 1: через меню (самый простой)

1. Посмотрите на **верхнюю строку экрана** (меню).
2. Нажмите на слово **Cursor** (слева, рядом с яблоком на Mac).
3. В выпадающем меню выберите **Settings** (Настройки).
4. В подменю нажмите **Cursor Settings** (Настройки Cursor).

   ```
   Cursor
   ├── About Cursor
   ├── Check for Updates
   ├── Settings
   │   ├── Cursor Settings   ← СЮДА
   │   ├── Keyboard Shortcuts
   │   └── ...
   └── ...
   ```

### Способ 2: через горячие клавиши

- Нажмите **Cmd + Shift + J** (на Mac) или **Ctrl + Shift + J** (на Windows/Linux).
- Откроется окно настроек Cursor.

### Способ 3: через Command Palette

1. Нажмите **Cmd + Shift + P** (Mac) или **Ctrl + Shift + P** (Windows/Linux).
2. В поисковой строке введите: `Cursor Settings`.
3. Выберите пункт **Cursor: Open Cursor Settings**.

---

## Часть 2. Найти раздел Auto-Run (Автозапуск)

После открытия Cursor Settings вы увидите окно с несколькими разделами слева.

1. В **левой колонке** найдите раздел **Agents** (Агенты).
2. Нажмите на него — откроется подменю.
3. Выберите пункт **Auto-Run** (Автозапуск).

   ```
   Левая колонка:
   ├── General
   ├── Models
   ├── Agents          ← нажмите сюда
   │   ├── Auto-Run    ← затем сюда
   │   └── ...
   ├── ...
   ```

Теперь вы в нужном месте. Дальше — настройки, которые нужно включить.

---

## Часть 3. Какие настройки включить

В разделе **Auto-Run** будут переключатели и списки. Ниже — что именно нужно сделать.

### 3.1. Auto-Run Mode (Режим автозапуска)

**Что это:** Режим, в котором AI выполняет команды (терминал, файлы и т.д.).

**Варианты:**
- **Run in Sandbox** — команды в ограниченной среде (по умолчанию).
- **Ask Every Time** — перед каждой командой спрашивать разрешение.
- **Run Everything** — всё выполнять автоматически, без ограничений.

**Что выбрать:**  
Включите **Run Everything**, чтобы AI мог сам запускать серверы без подтверждений.

---

### 3.2. Auto-Run Network Access (Доступ к сети)

**Что это:** Разрешает командам в песочнице обращаться в интернет (npm, Vite, бэкенд и т.д.).

**Что сделать:**  
Включите переключатель **Auto-Run Network Access** (если он есть).

---

### 3.3. Command Allowlist (Список разрешённых команд)

**Что это:** Список команд, которые AI может выполнять без подтверждения.

**Что сделать:**  
Добавьте в список такие команды (каждую с новой строки или через запятую, в зависимости от интерфейса):

```
npm start
npm run dev
npm install
node server.mjs
cd
```

Как добавить:
1. Найдите поле **Command Allowlist**.
2. Нажмите **Add** или **+**.
3. Введите команду, например `npm start`.
4. Повторите для остальных команд.

---

## Часть 4. Сохранить настройки

1. Закройте окно настроек (крестик или **Cmd + W**).
2. Настройки сохраняются автоматически.
3. При необходимости перезапустите Cursor.

---

## Часть 5. Проверка

После настройки попросите AI: «Запусти сайт на локалке».

AI должен:
1. Запустить бэкенд (`npm start` в папке `backend`).
2. Запустить фронтенд (`npm run dev` в папке `frontend`).
3. Сообщить адреса: сайт (обычно http://localhost:8080) и API (http://localhost:3001).

---

## Часть 6. Если настройки выглядят иначе

Интерфейс Cursor может отличаться в разных версиях. Ищите по смыслу:

| Что нужно | Как может называться |
|-----------|------------------------|
| Автозапуск команд | Auto-Run, Run Everything, Yolo mode |
| Доступ к сети | Network Access, Sandbox Networking |
| Список команд | Command Allowlist, Terminal Allowlist |

---

## Часть 7. Альтернатива: разрешать по одной команде

Если не хотите менять общие настройки:

1. Попросите AI запустить сайт.
2. Когда команда не выполнится, появится окно с вариантами.
3. Выберите **Add to allowlist** (Добавить в список разрешённых).
4. Команда будет выполняться без подтверждения в следующий раз.

Повторите для `npm start`, `npm run dev` и других нужных команд.

Если настройки не помогают, запускайте вручную.

```bash
npm install
npm start
```

### Вариант Б: два терминала

**Терминал 1 — бэкенд:**
```bash
cd /Users/litovchenkoartem/Documents/rus-ind111/backend
npm start
```

**Терминал 2 — фронтенд:**
```bash

npm run dev
```

### Где смотреть сайт

- Сайт: http://localhost:8080 (или порт, который покажет Vite)
- API: http://localhost:3001

## Краткая шпаргалка

1. **Cursor** → **Settings** → **Cursor Settings**
2. **Agents** → **Auto-Run**
3. Включить **Run Everything** (или добавить команды в **Command Allowlist**)
4. Включить **Auto-Run Network Access**
5. Закрыть настройки и попросить AI запустить сайт
